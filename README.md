# WCAG 2.2 Audit Checklist

A simple, interactive checklist for auditing against the Web Content Accessibility Guidelines (WCAG) 2.2.

## Features

- Filter by conformance level (A, AA, and/or AAA)
- Hide criteria you’ve already checked off, so you can focus on what’s left
- Each criterion includes a link to its official WCAG Understanding document for quick reference
- Progress saves automatically in the browser via local storage
- Light and dark theme
- Single HTML file (easy to download and use offline)

## Use it

**Online:** [https://willslone.github.io/wcag-checklist/](https://willslone.github.io/wcag-checklist/)

**Offline:** Download `index.html` from this repository and open it in any browser.
